# Условия производства текста как конфаундер оценки машинности

Публикационный экспорт исследования: код, производные данные, результаты прогонов,
таблицы и рисунки статьи.

**DOI:** [10.5281/zenodo.21749574](https://doi.org/10.5281/zenodo.21749574)
**Репозиторий:** https://github.com/staurus86/beyond-authorship-russian-ai-detection

## О чём работа

Оценки машинности текста сдвигаются от условий его производства при неизменном
происхождении. Мы сравнили три режима задания внутри машинного корпуса, где
происхождение постоянно по построению, и все четыре независимые операционализации
дали сдвиг с интервалом, не накрывающим ноль. Направление эффекта инвариантным не
было: три процедуры дали отрицательный контраст, модель-судья — положительный.

Корпус — 1882 документа на русском языке: 1079 машинных и 803 человеческих.

## Предупреждение о реестре

Реестр **псевдонимизирован, но не анонимен**. Прямые идентификаторы авторов заменены
кодами `author_NNNN`, однако ссылки на публичные первоисточники сохранены для
provenance — по ним автор публикации устанавливается. Таблица соответствия и секрет
перестановки не публикуются.

## Чего здесь нет

Исходных текстов человеческой части: они распространяются по лицензиям своих
источников. Репозиторий **воспроизводит анализ из опубликованной матрицы признаков**,
а не повторный сбор корпуса — скрипты сбора внешних источников в экспорт не входят.

## Быстрый запуск

```bash
python -m pip install -r requirements-lock.txt   # Python 3.14.0
python code/verify_release.py                    # все доступные проверки
python code/build_tables.py                      # 24 таблицы из результатов
python code/build_figures.py                     # 6 рисунков
```
