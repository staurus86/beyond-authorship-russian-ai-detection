# Abstract

Automated assessment of whether a text was machine-generated is applied where
the verdict carries a cost for the author, yet origin is a property of the
production process, not an observable property of the text. The conditions
under which a text was produced — how rigid the task was, the editorial rules,
the platform template — push it in the same direction in which a generative
model is presumed to push it.

This study measures the contribution of these conditions while origin is held
fixed. The Russian-language corpus of 1882 documents comprises a machine part,
generated by four generation channels — each backed by its own model family —
across 45 tasks in three task modes, and an
archival human part annotated for source regimentation level before the texts
were read. The primary contrast is computed within the machine corpus: both
halves of a pair are generated by the same model for the same task and differ
only in task wording. Machine-likeness is measured by four operationalisations
— an interpretable index with weights fixed before data collection, a trained
classifier, a zero-shot metric on an open model, and a judge model.

The main result is disagreement between procedures. Changing the task mode
shifted the scores of all four, but the direction did not match: three gave a
negative shift, the judge a positive one, and none of the four intervals
covers zero. The cross-procedure comparison plan and the specifications of
procedures 2–4 were fixed after the result of procedure 1 had been obtained
but before procedures 2–4 were run; the disagreement survived correction of a
corpus defect and of the nested validation.

Two observations explain why such scores cannot be read as measurements of
authorship. A baseline on a single feature — the source identifier — reaches a
median AUROC of 1.0000 across the thirteen group splits where AUROC is
defined, meaning that the origin
class is confounded with how the corpus was assembled. Removing emphasis
markers did not change the full text by a single character, yet it moved the
boundary between heading and prose, changed the format counters, and flipped a
confident machine verdict to human for every applicable model.

The scores should be interpreted as properties of a specific measurement
system and corpus, not as a direct measurement of text origin. The system
distinguishes not only linguistic style but traces of data collection,
repetition, formatting, and preprocessing decisions.
