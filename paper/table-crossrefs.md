# Карта ссылок на таблицы

Составлено 2026-08-01. Связывает markdown-таблицы исходных файлов разделов с
собранными таблицами `08-paper/tables/`. По этой карте расставляются якоря вставки
и ссылки «таблица N» в тексте.

Правило вставки: перед markdown-таблицей исходника ставится якорь
`<!-- ТАБЛИЦА N: tab-NN-slug -->`. Сама markdown-таблица остаётся на месте как
рабочая копия; при сборке LaTeX на её место идёт `\input{tables/tab-NN-slug.tex}`.
