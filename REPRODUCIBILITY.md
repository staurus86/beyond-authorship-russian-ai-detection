# Воспроизводимость: что пересчитывается, а что нет

Три уровня. Первый доступен всем, второй требует локальных моделей, третий —
исходных текстов, которых в репозитории нет.

## Уровень 1: из опубликованных производных данных

Пересчитывается полностью, без внешних ресурсов.

- контрасты первичного исхода O1 по четырём процедурам;
- классификатор, его варианты и ablation структурных признаков;
- метрики по 18 групповым holdout, fairness по подгруппам;
- калибровка, ECE, MCE и risk–coverage;
- сводка стресс-теста по десяти преобразованиям;
- 24 таблицы и 6 рисунков статьи.

Вход — `data/features/feature-matrix-v5.csv`, `data/splits-v5/` и файлы `results/`.

```bash
python code/build_tables.py
python code/build_figures.py
```

## Уровень 2: требует локальных моделей

Признаки семейства sem-v1 считаются моделью эмбеддингов, zero-shot NLL — языковой
моделью, оценки судьи — локальной моделью через Ollama. Модели и их ревизии указаны
в `README.md`; веса в репозиторий не входят.

Расхождения ожидаемы: эмбеддинги недетерминированы по порядку суммирования, и в
проекте измерен допуск — расхождение векторов до 3.5·10⁻⁷ при допуске 1·10⁻⁴.

## Уровень 3: требует исходных текстов

Не воспроизводится по опубликованным данным.

- препроцессинг и построение матрицы признаков с нуля;
- стресс-преобразования текста;
- разбор повторов и ручные карточки.

Человеческие тексты распространяются по лицензиям источников. Для каждого документа
реестр хранит URL, дату обращения и хеш нормализованного текста: получив текст у
источника, можно проверить, что это тот же документ.

## Что делает скрипт, если данных не хватает

Расчёт, которому нужны недоступные тексты, завершается понятным сообщением о том,
какого входа нет и на каком уровне воспроизводимости он находится.

## Проверка релиза

```bash
python code/verify_release.py
```

Скрипт сверяет `SHA256SUMS`, структуру каталогов, псевдонимизацию реестра и
отсутствие запрещённых путей.
