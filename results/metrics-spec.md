# Метрики

## 1. Определение происхождения

**Первичные**

| Метрика | Зачем |
|---|---|
| `TPR@1% FPR` | сценарий обвинения: сколько машинных текстов поймано при одном проценте ложных обвинений |
| `TPR@5% FPR` | мягкий операционный режим |
| FPR на hard-human | цена ошибки на формальной, переводной и неносительской прозе |
| MCC | устойчив к дисбалансу классов |
| Balanced accuracy | — |

**Вторичные:** AUROC, AUPRC, macro-F1, precision и recall по классам, матрица ошибок, Brier score, calibration error, coverage/error при отказе.

## 1.1. Что публикуется на тесте обязательно

Внесено 2026-07-24 по внешней рецензии. Страты различаются по численности почти вдвое — 181 против 108, — и одна усреднённая цифра это скроет.

| Срез | Зачем |
|---|---|
| micro-average | общая картина, взвешенная численностью |
| **macro-average по стратам** | равный вес страт: без него результат определяется самой крупной |
| метрики каждой страты отдельно | видно, где процедура работает, а где нет |
| **худший результат среди страт** | нижняя граница качества, а не средняя |
| FPR с доверительным интервалом | цена ошибки на людях с указанием точности оценки |
| FPR по каждой подгруппе hard-human | подгруппы §5.2.1 preregistration; документ входит в общий FPR один раз |

**Численность страт не выравнивается удалением документов.** Дисбаланс лечится случайными эффектами источника и автора, cluster bootstrap по источникам и macro-метриками. Выбрасывать 73 собранных текста ради визуального равенства нельзя.

**Inverse-frequency weights по умолчанию не применяются.** Они уместны только когда определена целевая популяция и известно, какое распределение страт она должна иметь. Ни того ни другого у нас нет.

**Зарегистрированная проверка дисбаланса.** Первичные исходы пересчитываются на 108 случайно выбранных документах страты 2, отбор стратифицирован по источнику и жанру, сид фиксируется в реестре до отбора. Совпадение результата означает, что дисбаланс несущественен; расхождение публикуется.

**В обучении классификатора** допустимы stratified sampling, class weights и balanced batches — это свойство процедуры обучения, а не состава корпуса.

AUROC единственной метрикой не выступает: высокая площадь под кривой сочетается с неприемлемым числом ложных срабатываний в рабочей точке.

## 2. Гибридные классы

- macro-F1 по классам;
- F1 на уровне предложения;
- span precision, recall, F1;
- IoU;
- ошибка определения границы перехода (для текстов с одним переходом);
- средняя абсолютная ошибка доли ИИ-правки, если разметка степени доступна.

## 3. Стиль и качество как отдельные выходы

Балл ИИ-стиля и балл редакторского качества оцениваются против человеческой разметки по своим шкалам и **не сводятся** в одну метрику. Проверяется корреляция между ними: гипотеза H9 предсказывает связь без совпадения.

## 4. Редактор (эксперимент этапа 13)

- сохранение фактов;
- сохранение чисел, дат, имён, ссылок и цитат;
- сохранение модальности;
- уменьшение семантических повторов;
- парное предпочтение людей вслепую;
- соответствие жанру;
- overshoot: доля правок, ушедших в карикатурную разговорность;
- доля выдуманных деталей.

Снижение detector score метрикой качества рерайта не является. Правка, принятая только потому, что упал балл детектора, отклоняется.

## 5. Отказ от вердикта

Публикуется: доля документов, по которым вывод не выдан, и ошибка на оставшемся покрытии. Система с высоким покрытием и высокой ошибкой хуже системы, которая честно отказывается на трудных случаях.

Условия отказа перечислены в `ai-human-style-lab-v0.2.0/SKILL.md`, §14.

## 6. Форма отчёта

Каждая метрика приводится с доверительным интервалом (cluster bootstrap по автору и документу) и по каждому срезу из `splits-spec.md`. Точечная оценка без интервала и без среза в статью не идёт.
