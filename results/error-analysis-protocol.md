# Протокол разбора ошибок

Ручной разбор, не автоматический отчёт. Минимальный объём:

- 50 ложноположительных (человеческий текст принят за машинный);
- 50 ложноотрицательных;
- 30 ошибок на гибридных классах;
- 30 нестабильных результатов из стресс-тестов;
- 30 документов с сильным несогласием разметчиков.

## Что заполнять по каждому случаю

| Поле | Что писать |
|---|---|
| `document_id` | — |
| Класс ошибки | FP · FN · hybrid · instability · disagreement |
| Сработавшие признаки | список с вкладом |
| Альтернативное объяснение | жанр, задание, длина, источник, перевод |
| Жанровая норма | ожидается ли этот признак в жанре |
| Prompt effect | требовалось ли заданием |
| Length effect | попадает ли длина в надёжный диапазон |
| Артефакт источника | разметка, CMS, шаблон площадки |
| Реальная редакторская проблема | есть или нет |
| Вывод | признак ошибочен · порог ошибочен · документ размечен неверно · случай неразрешим |

Файл: `error-analysis.csv` с этими полями.

## Claim-preservation при разборе рерайта

Для эксперимента этапа 13 к каждому переписанному тексту прикладывается карта утверждений: ID, тип (`FACT`, `NUMBER`, `DATE`, `QUOTE`, `OPINION`, `CAUSAL`, `LIMITATION`, `CTA`, `LEGAL`), статус после правки (`preserved`, `narrowed`, `strengthened`, `removed`, `needs review`).

Статусы `strengthened`, `removed` и любое изменение числа — блокирующий дефект. Версия с таким статусом в оценку качества не идёт.

## Что искать в ложноположительных

Три частые причины по литературе и полевому прогону:

1. **жанровая формальность** — регламент, инструкция, документация;
2. **исполнение жёсткого задания** — рубрикация, финальный вывод, отсутствие цифр при запрете их выдумывать;
3. **перевод или неносительский синтаксис**.

Если причина третья, случай попадает и в fairness-аудит.

## Что искать в ложноотрицательных

1. текст прошёл человеческую правку;
2. модель работала в anti-slop режиме;
3. новая модель без известных маркеров;
4. текст короче надёжного порога.

Случай 3 отдельно фиксируется как свидетельство устаревания признаков — это самостоятельный результат.
