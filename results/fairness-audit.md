# Fairness-аудит

FPR публикуется отдельно по каждой группе. Средняя цифра прячет ту группу, которую система обвиняет системно.

## Группы

| Группа | Откуда берётся | Почему уязвима |
|---|---|---|
| Неносители русского | внешний hard-human | измерено на английском: FPR 61.22% против ~5.1% у носителей (Liang et al., 2023) |
| Авторы с простой лексикой | hard-human, студенческие тексты | низкое лексическое разнообразие читается как машинное |
| Формальный и канцелярский стиль | регламенты, инструкции, ГОСТ | предсказуемость текста высокая по построению |
| Технические специалисты | документация | терминологическая однородность |
| Профессиональные редакторы | вычитанные публикации | отсутствие шероховатостей |
| Студенческие работы | учебные архивы | шаблонная структура |
| Переводы | переводные тексты | синтаксические кальки |
| Тексты после корректуры | правленые публикации | ровный ритм |
| Короткие документы | все классы, <300 слов | статистика ненадёжна |
| Длинные документы | все классы, >3000 слов | метрики длиннозависимы |

## Что считать

Для каждой группы: FPR, доверительный интервал, число документов, примеры ошибок, какие признаки сработали.

Отдельно — разность FPR между группой и общим человеческим набором с интервалом. Разность важнее абсолютных значений: она показывает, кого система наказывает сильнее прочих.

## Чего не делать

Не выводить характеристики автора из текста: национальность, образование, языковую компетенцию, возраст. Аудит меряет поведение системы, а не людей.

Не объявлять справедливость свойством технологии. Смещение измеряется для конкретной системы на конкретном корпусе, чужие результаты не переносятся.

## Порог допуска

Если разность FPR между любой уязвимой группой и общим набором превышает [порог], система не рекомендуется к применению в обвинительном сценарии, и это пишется в статье прямым текстом.

## Что попадает в статью

Таблица FPR по группам, разности с интервалами, минимум пять разобранных ложных срабатываний с объяснением сработавших признаков и альтернативной причиной.
