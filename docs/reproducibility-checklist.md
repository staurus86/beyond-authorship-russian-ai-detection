# Чеклист воспроизводимости

Заполняется перед подачей. Пункт без отметки — либо доделать, либо объяснить в limitations.

Этот чеклист проверяет, всё ли на месте к моменту подачи. Что и куда записывать **по ходу работы** — `logging-rule.md`. Незаписанное вовремя здесь уже не восстановить.

## Данные

- [ ] описан состав корпуса по языку, жанру, классу происхождения и длине
- [ ] указано, кто создавал тексты и в каких условиях (data statement)
- [ ] опубликованы лицензии и правовой статус каждой части
- [ ] описаны критерии включения и исключения, лог исключений приложен
- [ ] дедупликация выполнена, метод описан
- [ ] provenance graph зафиксирован: все версии текста в одном split

## Генерация

- [ ] для каждой модели указаны поставщик, точное имя, дата, интерфейс
- [ ] сохранены system prompt и user prompt
- [ ] зафиксированы temperature, top-p, seed, наличие веб-поиска или RAG
- [ ] сырые ответы сохранены без постобработки
- [ ] причины повторной генерации описаны заранее и залогированы
- [ ] отказы моделей помечены отдельным классом

## Признаки

- [ ] препроцессинг заморожен и описан: что попало во вход, что выброшено
- [ ] у каждого экстрактора есть версия
- [ ] пропуски описаны в missingness report
- [ ] проверена test-retest стабильность

## Анализ

- [ ] preregistration опубликован с датой
- [ ] confirmatory и exploratory результаты разделены
- [ ] разбиения описаны и воспроизводимы по манифесту
- [ ] сиды зафиксированы в реестре
- [ ] окружение зафиксировано (версии библиотек, lock-файл)
- [ ] скрипты запускаются на чистой машине по инструкции
- [ ] опубликованы effect size и доверительные интервалы, не только p-value
- [ ] применена поправка на множественные сравнения

## Метрики
