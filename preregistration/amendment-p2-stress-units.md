## 1. Что обнаружено

Дизайн стресс-теста P2 исходил из того, что каждому панельному документу соответствует ровно одна held-out модель. Тогда 60 документов × 11 преобразований дают 660 строк, и каждая строка — одна оценка.

Предположение неверно. Восемнадцать holdout-разбиений серии v2 диагностические: они режут корпус по разным осям — автор, жанр, модель, промпт, источник, время, тема. Документ выпадает в test сразу по нескольким осям, и его оригинал оказывается held-out для нескольких моделей одновременно.

Аудит панели против замороженных разбиений:

| Допустимых моделей на документ | Документов |
|---|---|
| 1 | 7 |
| 2 | 5 |
| 3 | 8 |
| 4 | 14 |
| 5 | 5 |
| 6 | 3 |
| 18 | 18 |

Сумма по 60 документам — **464 пары «документ × допустимый holdout»**. Одиннадцать преобразований дают **5104 модельные оценки**.

Восемнадцать документов с полным покрытием — подгруппа hard-human `human_hard_rusltc_*`, жанр `translation`. Проверено: ни один из них не входит в train ни одного holdout. Это свойство дизайна, а не дефект разбиений: подгруппа удерживается всегда, чтобы FPR на состязательном человеческом тексте измерялся вне обучения.

## 2. Единицы анализа

Пять величин, каждая со своим смыслом. Смешивать их запрещено.

| Величина | Число | Что это |
|---|---|---|
| Исходные документы | 60 | наблюдения панели |
| Первичные ячейки | 660 | `документ × преобразование` |
| Пары модель-документ | 464 | `документ × допустимый holdout` |
| Технические строки | 5104 | `документ × преобразование × holdout` |
| Знаменатель индекса | 11 | число доступных преобразований |

Знаменатель 11 относится к преобразованиям и не меняется. Название результата в статье остаётся `11-transformation stress test`.

**5104 строки не считаются независимыми наблюдениями.** Документ с восемнадцатью допустимыми моделями даёт восемнадцать строк на каждое преобразование, но остаётся одним наблюдением.

## 3. Правило агрегации P2

Без этого правила подгруппа RusLTC получила бы в восемнадцать раз больший вес, чем документ с одной моделью. Порядок свёртки задан здесь, до расчёта.

Шаг 1. Для каждой ячейки `документ × преобразование` усреднить по допустимым моделям:

```text
mean_delta_prob = mean(delta_prob по eligible holdout)
```

Шаг 2. Нестабильность считать по модулю, чтобы разные знаки не гасили друг друга:

```text
instability_rate = mean(|delta_prob| > 0.05 по eligible holdout)
```

Шаг 3. Смену решения — тем же способом:

```text
flip_rate = mean(decision_changed по eligible holdout)
```

Шаг 4. Полученные три величины агрегировать по 60 документам с равным весом каждого документа.

Шаг 5. Таблицу по каждому holdout публиковать отдельно. Интервалы для общего результата получать бутстрапом с кластеризацией по `document_id`.

Порог 0.05 в шагах 2 и 3 задан здесь и относится к шкале вероятности, а не к шкале 0–100. Порог 5.0 пункта из `analysis-closure.md` §6.1 к P2 не применяется — там же записано, что к процедурам вне шкалы 0–100 он напрямую неприменим.

## 4. Шлюзы этапа score

Статус `completed` присваивается при выполнении всех шести условий:

1. ровно 5104 строки, число совпадает с ожидаемым по аудиту;
2. каждая из 464 пар присутствует ровно для 11 преобразований;
3. нет лишних сочетаний `документ × split_name` вне аудита;
4. `verify_passed = true` — held-out вектор воспроизведён с допуском 1e-8;
5. у записей `applied_no_change` выполняется `|delta_prob| <= 1e-8`;
6. число первичных ячеек `документ × преобразование` после агрегации равно 660.

Провал условия 4 обрабатывается отдельно и жёстче: манифест получает `status: blocked`, `reason: frozen_model_not_reproducible`, файл `stress-p2a-scores.csv` не создаётся, код возврата ненулевой. Численно готовые результаты при незаверенной реконструкции не производятся вовсе.

## 5. Чего амендмент не делает

Разбиения не трогаются: holdout-раскладка остаётся перенесённой из v1, схема inner CV — та, что зарегистрирована `amendment-clf-v2-inner-cv.md`. Состав панели, список одиннадцати преобразований, сиды и порог 5.0 для P1 не меняются.

Модель на всём корпусе с фиксированным C не восстанавливается и в P2a не подменяет holdout-модели. Если такая процедура понадобится, она регистрируется отдельно как P2c.

Процедуры P1, P3 и P4 амендмент не затрагивает: там документ оценивается одним способом, и 660 ячеек остаются 660 строками.
